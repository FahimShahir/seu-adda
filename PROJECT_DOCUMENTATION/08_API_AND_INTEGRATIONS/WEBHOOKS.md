# Webhooks Integration Status

> [!NOTE]
> **NOT APPLICABLE**:
> SEU Adda does not use inbound or outbound HTTP webhooks. All inter-client communication is handled either through direct WebSocket MQTT messages (Mode A) or client-initiated HTTP short-polling against PHP REST endpoints (Mode B).
