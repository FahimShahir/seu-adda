# Current System Capabilities Baseline

1. **Interactive Campus Artwork**: 18 non-overlapping character hotspots with department attribution and mood-based dialogues.
2. **Headless YouTube Radio**: Background music streaming with curated playlists, custom YouTube link input, and zero visual clutter.
3. **Dual-Deployment Ephemeral Rooms**: 2-hour self-destructing rooms operating on GitHub Pages (MQTT) and InfinityFree (PHP MySQL).
4. **Strict Character Exclusivity**: 1-to-1 avatar allocation per room with live occupied badge locks.
5. **Real-Time Group Chat**: Floating speech bubbles above characters (30s lifespan) with full chat history log.
6. **Synchronized Room Music**: Sub-2-second song change synchronization across all room participants.
7. **Campus Confessions Wall**: Anonymous submission and real-time like incrementing.
8. **Campus Cheers Counter**: Global atomic tea clicks counter with confetti animation.
9. **Social Photo Card Generator**: Canvas-rendered digital campus postcards with PNG export.
10. **Alumni Corner**: Fahim Shahir developer profile with bKash personal micro-treat copy integration (`01969091751`).
