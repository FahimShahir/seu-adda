# Future Improvements & Architectural Evolution

## 1. Planned & Potential Enhancements

1. **WebRTC Spatial Voice Adda**:
   - Enable peer-to-peer audio chat with positional volume falloff based on avatar coordinates in the campus scene.
2. **Additional Campus Zones**:
   - Expand beyond the main courtyard to include the Rooftop Garden, Library Quiet Zone, and Basketball Ground.
3. **PWA (Progressive Web App) Installation**:
   - Add service worker caching and manifest for home-screen installation on Android and iOS devices.
4. **Dynamic Code-Splitting**:
   - Dynamically load `PhotoCardModal` and `DeveloperModal` on demand to reduce initial JS payload by ~30%.
