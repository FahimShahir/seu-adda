# Project Historical Context & Evolution

## 1. Project Genesis

**SEU Adda** was created by **Fahim Shahir** (Department of CSE, Southeast University) to preserve and celebrate campus friendships.

Initial versions were hosted purely statically on GitHub Pages. To satisfy student demands for custom domain hosting, persistent confession storage, and reliable database capabilities, the platform was expanded to **InfinityFree hosting** (`https://seuadda.free.nf/`).

## 2. Key Evolutionary Milestones

1. **Phase 1**: Static campus artwork with 18 character hotspots and Bengali dialogues.
2. **Phase 2**: Headless YouTube radio with curated nostalgic playlists and procedural rain sound.
3. **Phase 3**: Ephemeral private Adda rooms with QR/link sharing and speech bubbles via EMQX MQTT.
4. **Phase 4**: Migration to full-stack PHP 8.x + MySQL 8.x on InfinityFree with SQLite fallback.
5. **Phase 5**: Sub-2-second room music sync, 5-minute inactivity grace period, and auto-healing chat persistence.
6. **Phase 6**: Strict 1-to-1 unique character exclusivity per room with occupied badge locks.
7. **Phase 7**: Authoritative permanent technical documentation engine (`PROJECT_DOCUMENTATION/`).
