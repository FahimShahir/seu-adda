# SEU Adda — সাউথইস্ট বিশ্ববিদ্যালয় আড্ডাখানা ☕🎸

সাউথইস্ট বিশ্ববিদ্যালয় (Southeast University) ক্যাম্পাস চত্বরে আড্ডা, অ্যাকোস্টিক গিটারের গান, এক কাপ লাল চা আর বন্ধুদের সাথে নস্টালজিক মুহূর্ত উপভোগের একটি ভার্চুয়াল প্ল্যাটফর্ম।

## ✨ মূল বৈশিষ্ট্যসমূহ (Features)

1. **ইন্টারেক্টিভ ক্যাম্পাস আর্টওয়ার্ক (১৮টি নন-ওভারল্যাপিং হটস্পট)**:
   - ক্যাম্পাসের কেন্দ্রস্থলে বসা **অ্যাকোস্টিক গিটারিস্ট** স্পর্শ করলে গান শুরু হবে এবং গিটার কর্ডের শব্দ বাজবে।
   - ক্যাম্পাসের ১৮টি গ্রুপ ও ছাত্রছাত্রী (বাচাল দল, সিআর, গসিপ কুইন, শাড়ি পরা আপু, কোডার, ছ্যাঁকা খাওয়া প্রেমিক, সিঁড়ির ফিলোসফার গ্যাং, গেটের গার্ড মামা ইত্যাদি) প্রত্যেকের জন্য ৪টি মুডে (`আড্ডা`, `ছ্যাঁকা 💔`, `পরীক্ষা 📚`, `ক্যান্টিন ☕`) শত শত বাস্তবসম্মত ও হাস্যরসাত্মক কথোপকথন।
   - চা এর কাপে ক্লিক করলে গরম চায়ের ধোঁয়া এবং চিয়ার্স (Cheers! ☕) কনফেটি অ্যানিমেশন চালু হবে।
2. **হেডলেস ইউটিউব অডিও রেডিও (Headless YouTube Radio)**:
   - ব্যাকগ্রাউন্ডে হেডলেস YouTube IFrame প্লেয়ারের মাধ্যমে বিরতিহীন বাংলা ক্যাম্পাস, আর্টসেল, আর্নব, শিরোনামহীন এবং ব্যান্ডের গান।
   - বিভিন্ন কিউরেটেড প্লেলিস্ট নির্বাচন করার সুবিধা এবং নিজস্ব YouTube প্লেলিস্ট যুক্ত করার অপশন।
3. **দিন ও সন্ধ্যার ক্যাম্পাস আলো এবং রাতের ঝিঝি পোকার সাউন্ড (Night Ambiance)**:
   - ক্যাম্পাসের ঝুলন্ত লাইটে ক্লিক করে অথবা কন্ট্রোল বারের মাধ্যমে দিন এবং সন্ধ্যার ক্যাম্পাসে সুইচ করার সুযোগ।
   - রাত অন করলে স্বয়ংক্রিয়ভাবে ঝিঝি পোকার ডাক ও রাতের শান্ত বাতাসের অ্যাম্বিয়েন্ট অডিও সিন্থেসিস ফেড-ইন হয়।
4. **বৃষ্টি ভেজা আবহ ও অ্যাম্বিয়েন্ট সাউন্ড (Rain & Ambiance)**:
   - ক্যাম্পাসের উঠোনে ক্যানভাস রেইন পার্টিকেল ইফেক্ট এবং সফট অ্যাম্বিয়েন্ট রেইন সাউন্ড।
5. **ফুল ইমেজ ও টাচ-স্ক্রোল ড্র্যাগ সিস্টেম (Touch Swipe & Zero Scrollbars)**:
   - পিসি এবং মোবাইল উভয় ডিভাইসেই ইমেজ কোনো কাটছাঁট ছাড়া সম্পূর্ণ দৃশ্যমান।
   - হেডার ও বটম প্লেয়ার সরাসরি আর্টওয়ার্কের উপর গ্লাস ইফেক্ট হিসেবে ভেসে থাকে।
   - কোনো কুৎসিত স্ক্রলবার নেই; আলতোভাবে টাচ করে বা ড্র্যাগ করে মসৃণভাবে সোয়াইপ করা যায়।
6. **লাইভ স্টুডেন্ট কাউন্টার ও ক্যাম্পাস স্মৃতি বোর্ড (Live Presence & Memories Board)**:
   - এই মুহূর্তে কতজন শিক্ষার্থী আড্ডায় যুক্ত আছেন তার লাইভ কাউন্টার।
   - ক্যাম্পাস কনফেশন এবং পুরোনো স্মৃতি শেয়ার ও লাইক দেওয়ার ইন্টারঅ্যাক্টিভ বোর্ড।

## 🚀 গিটহাব পেজে হোস্ট ও চালানোর নিয়ম (GitHub Pages Deployment)

এই প্রজেক্টটি সরাসরি **GitHub Pages**-এ চালানোর জন্য সম্পূর্ণ প্রস্তুত:

### পদ্ধতি ১: GitHub Actions দিয়ে অটোমেটিক ডিপ্লয় (সবচেয়ে সহজ)
1. গিটহাবে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `seu_adda`)।
2. কোডগুলো পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for SEU Adda"
   git branch -M main
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/seu_adda.git
   git push -u origin main
   ```
3. আপনার গিটহাব রিপোর **Settings** > **Pages** ট্যাবে যান:
   - **Source** হিসেবে **GitHub Actions** নির্বাচন করুন।
   - `.github/workflows/deploy.yml` নিজে থেকেই কয়েক সেকেন্ডে সাইটটি লাইভ করে দেবে!

### পদ্ধতি ২: লোকাল কম্পিউটার থেকে এক ক্লিকে ডিপ্লয় (gh-pages)
1. টার্মিনালে নিচের কমান্ডটি চালান:
   ```bash
   npm run deploy
   ```
2. এটি অটোমেটিক বিল্ড করে `gh-pages` ব্রাঞ্চে আপলোড করে দেবে।

```bash

npm run dev

# প্রোডাকশন বিল্ড টেস্ট
npm run build
```
